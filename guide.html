STEP 1
처음 시작하기
앱 설치 없이 링크만으로 바로 시작할 수 있어요.
1

링크 접속

공유받은 링크를 Chrome 브라우저로 열어요.
삼성 인터넷보다 Chrome이 더 잘 동작해요.

💡 iOS(아이폰)는 Safari도 OK
2

방 만들기 또는 참여하기

방 만들기 → 방 이름, 내 이름 입력 후 생성
기존 방 참여 → 방장에게 받은 5자리 코드 입력

🔑 방 코드는 상단 코드 칩을 탭하면 복사돼요
3

알림 허용

팝업이 뜨면 허용을 눌러야 새 메모 알림을 받을 수 있어요.

4

홈 화면에 추가 (선택)

Chrome 메뉴 → 홈 화면에 추가하면 앱처럼 바로가기가 생겨요. 방마다 별도 아이콘이 만들어져요.

📱 아이콘 이름 = 방 이름으로 자동 설정
FEATURE 01
실시간 메모 공유
가족이 각자 메모를 남기고 실시간으로 함께 볼 수 있어요.
✏️
메모 작성
일정, 부탁, 공유 사항 등 자유롭게
하단 입력창에 내용을 입력하고 ↑ 버튼을 누르면 돼요. 최대 500자까지 작성할 수 있고, Enter는 줄바꿈 / Ctrl+Enter는 전송이에요.
💡 HOW TO USE
  • 📝 하단 입력창 탭 → 내용 입력 → ↑ 버튼
  • 👤 내 이름 + 색상으로 자동 구분돼요
  • 📸 등록된 가족은 프로필 사진이 표시돼요
🔧
메모 수정 · 삭제
내용 변경이나 정리가 필요할 때
수정은 가족 누구나 할 수 있어요. 삭제는 본인이 작성한 메모만 가능해요. 수정된 메모에는 누가 수정했는지 표시돼요.
  • ✏️ 메모 카드의 연필 버튼 → 내용 수정 후 저장
  • × 메모 카드의 × 버튼 → 내 메모 삭제 (본인만)
✓
완료 처리
처리된 일정은 하단으로 정리
완료된 메모는 취소선 + 완료 배지가 붙고 목록 하단으로 이동해요. 언제든지 취소할 수 있어요.
  • ✓ 메모 카드의 ✓ 버튼 탭 → 완료 처리
  • ↩ 완료된 메모의 ↩ 버튼 → 완료 취소
⠿
순서 변경 (드래그)
중요한 메모를 위로 올릴 때
메모 카드를 길게 누르면 드래그 모드가 시작돼요. 원하는 위치로 끌어다 놓으면 순서가 바뀌고 모든 가족에게 실시간 반영돼요.
  • 👆 메모 카드 0.5초 길게 누르기 → 진동 피드백
  • ↕️ 드래그해서 원하는 위치로 이동
  • ✅ 손 떼면 위치 확정 + 자동 저장
FEATURE 02
주간 학원 시간표
아이의 학원 일정을 한눈에 확인해요. 요일별로 정리되어 항상 상단에 고정돼요.
📚
일정 추가 · 수정
학원, 과외, 활동 등 등록
+ 일정 추가 버튼으로 학원명, 요일, 시작/종료 시간을 입력하면 해당 요일 칸에 자동으로 표시돼요. 색상은 학원별로 자동 배정돼요.
  • ➕ 우측 상단 + 일정 추가 버튼 탭
  • 📝 학원 이름, 요일, 시작/종료 시간 입력 후 저장
🔍
일정 상세 보기 · 수정 · 삭제
터치 방식에 따라 다른 동작
일정 박스의 터치 방식에 따라 두 가지 동작을 해요.
  • 👆 짧게 탭 → 학원명 + 시간 확대 풍선 표시
  • 👇 길게 누르기 (0.5초) → 수정 / 삭제 팝업
FEATURE 03
실시간 알림
가족이 새 메모를 올리거나 수정하면 푸시 알림으로 알려줘요.
🔔
푸시 알림
앱을 안 열어도 알람이 와요
새 메모 작성 시 📌 방이름으로, 수정 시 ✏️ 방이름으로 알림이 와요. 본인이 작성/수정한 내용은 알림이 오지 않아요.
  • 👥 방에 2명 이상 메모를 남겼을 때만 발송
  • 🔕 본인 작성/수정은 알림 없음
  • 📱 앱이 닫혀있어도 알림 수신 가능
⚠️

알림이 안 온다면?

앱 접속 시 뜨는 알림 허용 팝업에서 허용을 눌러야 해요. 거부했다면 Chrome 설정 → 사이트 설정 → 알림에서 허용으로 바꿔주세요.

📱

아이폰 사용자 안내

메모 공유, 시간표 등 핵심 기능은 정상 동작해요. 단, iOS Safari의 FCM 제한으로 백그라운드 푸시 알림은 지원이 제한될 수 있어요.

TIPS & FAQ
자주 묻는 질문
사용하면서 궁금한 점들을 모았어요.
Q
방 코드를 어떻게 공유하나요? ▾
앱 상단의 방 코드 칩(예: K7X2M)을 탭하면 코드가 자동으로 복사돼요. 카카오톡 등으로 가족에게 공유하면 됩니다.
Q
다른 가족도 이 앱을 써야 하나요? ▾
네, 가족 모두가 같은 링크로 접속해서 같은 방 코드로 참여해야 함께 사용할 수 있어요. 링크를 카카오톡으로 공유하고 방 코드를 알려주면 돼요.
Q
여러 가족이 동시에 같은 방을 쓸 수 있나요? ▾
네! 실시간으로 동기화돼요. 한 명이 메모를 쓰면 다른 가족의 화면에도 즉시 나타나요. 인터넷 연결 상태에 따라 약간의 딜레이가 있을 수 있어요.
Q
앱을 새로 업데이트하면 어떻게 되나요? ▾
앱을 다음에 열 때 자동으로 최신 버전으로 업데이트돼요. 따로 설치하거나 업데이트할 필요가 없어요. 기존 데이터(메모, 시간표)는 그대로 유지돼요.
Q
다른 가족(친구네 등)과 같이 쓸 수 있나요? ▾
네, 완전히 다른 방을 만들면 돼요. 각 방은 5자리 고유 코드로 분리되어 있어서 서로 다른 가족이 독립적으로 사용할 수 있어요. 홈 화면에 추가하면 방마다 별도 아이콘이 생겨요.
Q
로그아웃은 어떻게 하나요? ▾
상단 내 이름 옆 ↩ 버튼을 누르면 로그아웃돼요. 다시 접속하면 자동으로 로그인됩니다.
